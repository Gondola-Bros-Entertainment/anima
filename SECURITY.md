# Security policy

Anima is under active development. Security fixes target the current `main`
branch; there are no maintained release branches yet.

## Report a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/Gondola-Bros-Entertainment/anima/security/advisories/new)
to report suspected vulnerabilities. Include the affected revision, build options,
platform, reproduction steps and expected impact. A minimal synthetic asset or
test case is especially useful for parser and runtime issues.

Keep exploit details and sensitive data out of public issues and pull requests.
Do not include live credentials, personal data or assets you cannot share. The
maintainers will review reports privately and coordinate fixes and disclosure
through GitHub security advisories.

## Scope

Reports may cover Anima's importers, scene and prefab readers, runtime modules,
desktop integrations or repository automation. Include the dependency version
when an issue appears to originate in an optional backend or vendored library.
Ordinary build failures and feature requests belong in public issues.
